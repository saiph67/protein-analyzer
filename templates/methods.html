How to report your results

  1. Name the tool and version, e.g. "analysed with Protein Analyzer {{ app_version }} (UniProtKB release {{ release.release or "YYYY_MM" }})".
  2. Cite the data sources you used (below). They did the scientific work; their licences require attribution.
  3. Name the method for each number, e.g. "pI calculated with Bjellqvist pK values (ExPASy method)".
  4. For anything central to your conclusions, cross-check with the standard tool (listed per method below). This app is a teaching and exploration tool and has not been peer-reviewed.
  5. Never use the function classifier or AlphaMissense as proof; treat them as hypotheses to test.
